# Lessons learned

1. Identify the specific mismatch between the delivered result and the operator's
   expectation. Use the affected task and its acceptance criteria to locate the cause.
2. Correct the deliverable and update the source that governs future work. Product
   decisions belong in PRODUCT_CONTEXT.md, reusable engineering principles in
   ENGINEERING_HARNESS.md and repository procedures in worklog/WORKFLOW.md.
   A task-specific clarification belongs in the affected task. Add a general
   rule only when the feedback establishes a reusable requirement.
3. Update affected active plans, templates or instructions that would still lead
   to the same mistake. Preserve completed records and link the correction to the
   original task.
4. Add a dated entry to the current numbered agent report following the
   [task workflow](../../../worklog/WORKFLOW.md). Record the feedback, the
   change, verification and any unresolved question or next action.
5. Before resuming related work, follow the documented entry point and confirm
   that a future agent can reach and apply the correction without chat history.
