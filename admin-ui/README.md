# CredØ instance admin UI

This Vue 3 application provides login and management screens for a CredØ instance. It calls the backend's session-authenticated endpoints under `/admin/`. The planned self-hosted Docker image includes this UI. In the paid hosted offering, customers will open it from the shared SaaS portal.

Follow the [local setup](../README.md#run-locally) to start the backend and Vite together. Run `npm run build` in this directory to build the frontend assets.
